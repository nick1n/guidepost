# Reporting discipline

Use the [report template](report-template.md) and main skill's completion gates. Lead with the most consequential observed findings,
then explain scope and verification limits. Rank by user impact rather than filling a fixed number of slots.

For each finding, preserve concrete reproduction steps, expected and observed behavior, and evidence. Merge repeated symptoms of one
root cause while identifying every affected surface. Separate suggestions from demonstrated failures and keep unverified findings open.

Review your draft against the evidence: remove generic advice, duplicate findings, unsupported certainty, and claims that exceed the
tested scope. Independent review can help with complex or consequential findings when authorized, but does not replace this self-check
or require a separate agent for every audit. Do not change repository instructions or PR templates merely to enforce report formatting.
